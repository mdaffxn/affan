# Affan Mini Game Arcade

This is a simple static website with 20 mini game cards.

## Save files to your computer
When you open the website, use the **Download** buttons at the top to save:
- `index.html`
- `styles.css`
- `script.js`

## Run locally
```bash
python3 -m http.server 8000
```
Open: `http://localhost:8000`

## Publish on GitHub Pages
1. Create a repository (for example `affan.github.io`).
2. Upload the 3 website files listed above.
3. In GitHub: **Settings → Pages → Deploy from a branch → main / root**.
4. Wait 1–2 minutes for the site URL.
